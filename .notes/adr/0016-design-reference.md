# 0016. Design reference

- Status: Accepted
- Date: 2026-11-15

## Context and problem statement

The look and interaction model should come from one agreed reference.

## Decision

The Archidocs Prototype canvas.

The prototype sets colours, type, spacing and screen arrangement. The requirements win wherever they differ, and the design is matched, not pixel-copied.

## Consequences

- Good: one visual direction.
- Bad: the prototype keeps state in memory and does not show links, sub-path hosting or clean layout rules.
