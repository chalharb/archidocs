# 0004. LLM and MCP

- Status: Accepted
- Date: 2026-11-15

## Context and problem statement

Assistants are a way to ask questions of a model and to author diagrams, but an MCP endpoint alone does not set Archidocs apart.

## Decision

A goal and a differentiator, not the goal.

LLM and MCP features arrive in later releases (2, 3 and 7) and are never required to read the site.

## Consequences

- Good: the first release stays focused on a polished, static viewer.
- Bad: the headline differentiator waits for later releases.
