## Context and problem statement

There is no outside team yet, so there is nobody to ask what a useful architecture site looks like.

## Decision

The builder, using reference models such as "Big Bank plc".

Work is done against realistic reference models and moves to a real team's model as soon as one exists. Sample content inside the package exists only as test fixtures and the `init` starter.

## Consequences

- Good: real-sized input shapes the product early.
- Bad: the reference model is invented, so it may miss what a real team's model needs.
