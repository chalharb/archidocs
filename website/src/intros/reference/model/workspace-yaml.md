`workspace.yaml` is the one file at the root of the Workspace folder. It defines the [Teams](/docs/concepts/teams-and-ownership/) that own Elements and the [Environments](/docs/concepts/deployments/) that Services run in, once, so every Project means the same thing by `payments` or `prod`. Everything else belongs to a Project.

The [Kitchen sink](/docs/examples/kitchen-sink/)'s:

