Big Bank plc is a fictional bank, after the internet banking example of the [C4 model](https://c4model.com). Five Teams each own a Project, and the Projects depend on each other, so it shows what Archidocs is for: one answer about an architecture that no single Team holds.

[Open the live demo ↗](https://big-bank.archidocs.dev) · [Source on GitHub](https://github.com/chalharb/archidocs/tree/main/examples/big-bank)

## The Workspace

| Project | Team | What it holds |
| --- | --- | --- |
| `digital` | Digital Banking | The customer, internet banking (web, single-page and mobile apps, the API and its Components), notifications |
| `core` | Core Banking | The mainframe, the ATM network, and the staff who use them |
| `identity` | Identity | Customer sign-in: the Auth Service and the user directory |
| `payments` | Payments | The Payments Service, fraud detection and the External card network |
| `platform` | Platform | The AWS region and its clusters, Kafka, e-mail |

```yaml file="examples/big-bank/archidocs/workspace.yaml"
```

There are two Environments, staging and production. The Platform Team declares the shared Deployment Targets that the other Teams deploy onto; the Core Banking Team declares its own data centre.

## Its history

The demo is built from four dated commits that replay how the bank's Model grew: internet banking and the mainframe, then the move of sign-in to the Identity Platform, then Payments and the Event Bus, then the Saved Views. In the viewer, pick a Revision to see the bank as it was, or Compare two. Five ADRs record the decisions along the way, one of them superseded and one still proposed.

## Things to try

- [Everything upstream of the mainframe](https://big-bank.archidocs.dev/#/view/c2?impact=core:mainframe&way=upstream), on the Service Landscape.

- Compare the first Revision with the latest to see what was added since launch.

Then ask the same questions of an agent: serve the demo's Bundle read-only with `archidocs mcp --bundle https://big-bank.archidocs.dev/workspace.bundle.json` and [connect your agent](/docs/guides/agents/connect-mcp/).
