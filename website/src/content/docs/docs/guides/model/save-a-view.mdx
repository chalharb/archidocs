Write a [Saved View](/docs/reference/glossary/#term-saved-view), a View a Project keeps as a query over the Model, so a question that comes up often has a link that stays current.

:::note[For agents]
The agent topic for this task is [`saved-view`](/docs/reference/agent-guide/saved-view/).
:::

## Before you start

- The Elements the View shows are in the Model. See [Add a Service](/docs/guides/model/add-a-service/).
- No Generated View answers the question already: `c1`, `c2`, `c2/<system>`, `c3/<service>` or `deployment/<environment>`. See [Views](/docs/concepts/views/).

## 1. Build it in the viewer

Run `archidocs dev`. Get the screen to answer the question: open what needs opening and turn on a Lens. Then use **Save as View**, which gives you the View as YAML.

## 2. Add it to the Project

Paste it under `views` › `structural` in the Project's `views.yaml`, keyed by an id unique among the Project's Views:

```yaml file="examples/kitchen-sink/archidocs/sink/views.yaml" region="structural"
```

`title` and `level` are required. The selectors that `include` and `exclude` take, and the Lenses, are in the [Saved Views reference](/docs/reference/model/views-yaml/#selector).

## 3. Check the Workspace

```bash
archidocs check
```

```text
0 errors, 0 warnings
```

## Check it worked

In the viewer, open the View from the **Views** tree. It draws the same diagram you saved:

<Diagram view="kitchen-sink/sink:orders-db-outage" alt="The Kitchen sink Services that depend on Orders DB, marked by how far upstream they are." />

Once published, its link is `#/view/<project>:<id>` in the viewer.

## If it didn't

`check` reports [`empty-view`](/docs/reference/rules/empty-view/) when the View's selectors match nothing. Check the ids it names.

`check` reports [`oversized-view`](/docs/reference/rules/oversized-view/) when the View is too big to read. Narrow its `include`, or split it in two.

## With an agent

[`upsert_view`](/docs/reference/mcp/write-tools/#upsert_view) writes a View. [`get_view`](/docs/reference/mcp/read-tools/#get_view) shows what it resolves to.
