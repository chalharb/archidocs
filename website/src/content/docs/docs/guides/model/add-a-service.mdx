Declare a [Service](/docs/reference/glossary/#term-service), something your Team deploys, so it appears on the diagrams and agents can find it.

:::note[For agents]
The agent topic for this task is [`add-service`](/docs/reference/agent-guide/add-service/).
:::

## Before you start

- The Project that owns the Service exists. See [Add a Project](/docs/guides/model/add-a-project/).
- You know whether the Service belongs to a System. See [Elements](/docs/concepts/elements/).

## 1. Declare the Service

Put it under its System's `services`, or under a top-level `services` key if it belongs to no System. Its id must be unique in the Project. Big Bank's Payments System holds this one:

```yaml file="examples/big-bank/archidocs/payments/model.yaml" region="payments-service"
```

Only `name` is required. Every other field, such as `type`, `external` and `owner`, is in the [Elements and Relationships reference](/docs/reference/model/model-yaml/#services).

If the System is declared in another file of the Project, declare the Service at the top level of its own file and attach it with `in`:

```yaml file="examples/kitchen-sink/archidocs/sink/reporting.yaml"
```

## 2. Add its Components

List the parts of the Service that people talk about by name under its `components`. Leave this out for an External Service, which has none. The fields are in the [`components` reference](/docs/reference/model/model-yaml/#components).

## 3. Connect it

Declare what the Service depends on under its `relationships`. See [Connect Services](/docs/guides/model/connect-services/).

## 4. Deploy it

Add a Deployment for each Environment it runs in, with its URL. See [Add Deployments](/docs/guides/model/add-deployments/).

## 5. Check the Workspace

```bash
archidocs check
```

```text
0 errors, 0 warnings
```

## Check it worked

Run `archidocs dev`, press `/` and find the Service by name. The Element panel shows its description, its Owner and its Relationships.

## If it didn't

`check` reports [`duplicate-id`](/docs/reference/rules/duplicate-id/) when another Element or Deployment Target in the Project has the same id. Choose another id.

`check` reports [`external-with-components`](/docs/reference/rules/external-with-components/) when an External Service lists Components. Remove them, or remove `external: true`.

## With an agent

[`upsert_element`](/docs/reference/mcp/write-tools/#upsert_element) adds a Service, or a Component with a `parent`, and returns the diff. Relationships and Deployments have tools of their own.
