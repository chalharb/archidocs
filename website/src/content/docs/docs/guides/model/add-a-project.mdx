Add a [Project](/docs/reference/glossary/#term-project), one Team's folder in the Workspace, so the Team can declare what it owns.

:::note[For agents]
The agent topic for this task is [`bootstrap`](/docs/reference/agent-guide/bootstrap/), which also declares the Project's contents from its code.
:::

## Before you start

- You have a Workspace. See the [Quick start](/docs/start/quick-start/).
- You know which Team will own the Project. See [Workspace and Projects](/docs/concepts/workspace-and-projects/) for how Projects split the Workspace.

## 1. Define the Team

The Team must be defined in `workspace.yaml`. Add it under `teams` if it is new:

```yaml file="examples/big-bank/archidocs/workspace.yaml"
```

## 2. Create `project.yaml`

Create a folder under the Workspace folder, named after the Project's id. Add a `project.yaml` to it:

```yaml file="examples/big-bank/archidocs/identity/project.yaml"
```

Other Projects name this one's Elements by the `id`, as `identity:auth-service`, so choose it with care. Every field is in the [`project.yaml` reference](/docs/reference/model/project-yaml/).

## 3. Declare its Elements

Add a file such as `model.yaml` beside `project.yaml`. Big Bank's Identity Project is one System with two Services:

```yaml file="examples/big-bank/archidocs/identity/model.yaml"
```

To fill it in, [add Services](/docs/guides/model/add-a-service/) and [connect them](/docs/guides/model/connect-services/).

## 4. Route its reviews

Add a line per Project to `CODEOWNERS`, so each change goes to the Team that owns it:

```text title="CODEOWNERS"
/archidocs/identity/  @bigbank/identity
```

## 5. Check the Workspace

```bash
archidocs check
```

```text
0 errors, 0 warnings
```

## Check it worked

Run `archidocs dev` and open the C2 Landscape. The new Project's Systems are on it, with the Team as their Owner in the Element panel.

## If it didn't

`check` reports [`unknown-team`](/docs/reference/rules/unknown-team/) when an `owner` names a Team that `workspace.yaml` doesn't define:

```text
archidocs/shop/model.yaml:6:12  error  unknown-team  Unknown Team "paymnets"; did you mean "payments"?

1 error, 0 warnings

Rule docs:
  unknown-team  https://archidocs.dev/docs/reference/rules/unknown-team/
```

Correct the name, or add the Team to `workspace.yaml`.

`check` reports [`nested-project`](/docs/reference/rules/nested-project/) when a Project folder sits inside another. Move it up a level.

## With an agent

[`create_project`](/docs/reference/mcp/write-tools/#create_project) writes the folder and `project.yaml`. [`upsert_team`](/docs/reference/mcp/write-tools/#upsert_team) adds a missing Team. To model an existing codebase in one go, see [Bootstrap a Project from code](/docs/guides/agents/bootstrap-from-code/).
