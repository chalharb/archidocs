Install the `archidocs-authoring` skill, so a coding agent loads the authoring guide before it edits the Model.

## Before you start

- The Archidocs CLI is installed. See the [Quick start](/docs/start/quick-start/).
- You know what the skill and the guide are for. See [Agents and MCP](/docs/concepts/agents-and-mcp/).

## 1. Install it in the Workspace repo

`archidocs init` installs the skill with the Workspace. From the repo root:

```bash
archidocs init
```

```text
Wrote archidocs/workspace.yaml
Updated .gitignore
Wrote .agents/skills/archidocs-authoring/SKILL.md
Wrote .claude/skills/archidocs-authoring/SKILL.md
Wrote .github/skills/archidocs-authoring/SKILL.md
Updated AGENTS.md

Register the Archidocs MCP server with your coding agent, started from the repo root:

  archidocs mcp --workspace archidocs
```

It writes the skill into each folder where coding agents look for skills. It adds an "Architecture model" section to `AGENTS.md`, and to `CLAUDE.md` if there is one.

## 2. Install it in a code repo

Skip this step unless agents edit the Model from a repo that holds code, not the Workspace. Clone the Workspace repo beside it, then run this in the code repo:

```bash
archidocs init --skill --workspace ../architecture/archidocs
```

```text
Wrote .agents/skills/archidocs-authoring/SKILL.md
Wrote .claude/skills/archidocs-authoring/SKILL.md
Wrote .github/skills/archidocs-authoring/SKILL.md
Updated AGENTS.md

Register the Archidocs MCP server with your coding agent, started from the repo root:

  archidocs mcp --workspace ../architecture/archidocs

Point --workspace at a local checkout of the Workspace repo, relative to where the coding agent starts the server.
```

`--workspace` is the path to the Workspace checkout. Register the command it prints, as [Connect an agent over MCP](/docs/guides/agents/connect-mcp/#in-a-code-repo) shows.

## 3. Keep it current

Run `archidocs init` again after upgrading the CLI. It rewrites the skill files if they changed and leaves everything else alone.

## Check it worked

Ask the agent to add a Service. It loads the authoring guide first, with `archidocs guide` or the MCP [`get_authoring_guide`](/docs/reference/mcp/read-tools/#get_authoring_guide) tool.

To read what it reads, run the same command:

```bash
archidocs guide
```

The first lines are the skill's name and description:

```text
---
name: archidocs-authoring
description: Edit the Archidocs architecture Model. Use when bootstrapping a Project from code, adding or changing Services, Relationships, Deployments or Views, or proposing an ADR.
---
```

`archidocs guide <topic>` prints one task, such as [`add-service`](/docs/reference/agent-guide/add-service/). The guide for the latest release is also under [Authoring guide for agents](/docs/reference/agent-guide/).
