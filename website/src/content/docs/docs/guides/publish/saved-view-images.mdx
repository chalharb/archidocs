Publish a picture of every [Saved View](/docs/reference/glossary/#term-saved-view) with the site, at a URL that never changes, so a wiki page or README always shows the latest Model.

## Before you start

- The site publishes from CI. See [Publish to GitHub Pages](/docs/guides/publish/github-pages/) or [Publish to GitLab Pages](/docs/guides/publish/gitlab-pages/).
- The Workspace has at least one Saved View. See [Save a View](/docs/guides/model/save-a-view/).

## 1. Turn images on

On GitHub, set the Action's `images` input:

```yaml title=".github/workflows/architecture.yml"
      - uses: chalharb/archidocs@v1
        id: archidocs
        with:
          images: true
```

On GitLab, set the [template](/docs/guides/publish/gitlab-pages/)'s `images` input to `true`.

## 2. Embed one

Each Saved View is drawn to `views/<view-id>.svg` in the site, with any `/` in its id turned into `-` and any `:` into `_`. Embed it, and link it to the same View in the viewer so readers can explore it:

```markdown title="README.md"
[![Checkout impact](https://<owner>.github.io/<repo>/views/shop_checkout-impact.svg)](https://<owner>.github.io/<repo>/#/view/shop:checkout-impact)
```

## Check it worked

After the next deploy, open a View's picture, such as `https://<owner>.github.io/<repo>/views/shop_checkout-impact.svg`. The picture is styled like the viewer and drawn for the latest Revision.

To see which files CI writes, run the same command locally:

```bash
archidocs export --all-saved --out views
```

```text
Wrote views/digital_mainframe-outage.svg
Wrote views/digital_prod-deployment.svg
Wrote views/digital_sign-in.svg
Wrote views/digital_sign-in-path.svg
Wrote views/payments_make-a-payment.svg
```

## If it didn't

If the picture's URL is not found, check the file name: `/` in the View id becomes `-` and `:` becomes `_`. A Generated View, such as `c2`, gets no picture; [save it as a View](/docs/guides/model/save-a-view/) first.
