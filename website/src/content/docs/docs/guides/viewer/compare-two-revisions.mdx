See how the system has changed between two [Revisions](/docs/reference/glossary/#term-revision), commits that changed the Model, and read the decisions behind an Element.

## Before you start

- You have a published viewer open, such as the [Big Bank demo ↗](https://big-bank.archidocs.dev). `archidocs dev` shows only the working tree. See [Publish to GitHub Pages](/docs/guides/publish/github-pages/).

## 1. Open a past Revision

Open **Revisions** in the location bar. It lists each Revision with its commit, message, date and how many [Changes](/docs/reference/glossary/#term-change) it made. Select **Open** to see the whole viewer as it was then.

A banner names the Revision. Select **Back to latest** to leave it.

## 2. Compare it with the latest

In **Revisions**, select **Compare** beside the older Revision. The diagram marks what was added, removed and changed since, and the Changes list beside it names each one:

<Screenshot id="viewer-compare" alt="The Service Landscape in Compare from fd11cd1 to the latest. The Changes list shows 35 Changes, and the Payments System, the Card Network and the Event Bus are marked as added." />

Select a Change to find it on the diagram. To compare two past Revisions, open the newer one first, then compare it with the older one.

The **History** tab of an Element panel lists only the Revisions that changed that Element, each with **Compare**.

## 3. Read the decisions behind an Element

Select the [Element](/docs/reference/glossary/#term-element), then the **ADRs** tab of its Element panel. It lists the [ADRs](/docs/reference/glossary/#term-adr), the decision records, that link it or anything inside it. Select one to open it in the ADR reader:

<Screenshot id="viewer-adr-reader" alt="The ADR reader open on digital:0002, Delegate sign-in to the Identity Platform: Accepted on 2025-07-21, linked to the Security Component and the Auth Service, and superseding digital:0001." />

## Check it worked

The location bar shows a **Compare** chip with both Revisions, and the address ends in `vs=` and the older one. On the demo, [Compare against 21 July 2025 ↗](https://big-bank.archidocs.dev/#/view/c2?vs=2025-07-21) marks Payments and the Card Network as added.

## If it didn't

The **History** tab says "This site has no history." The site was built from a clone without the git history. Build it from a full clone: see [Revisions and history](/docs/concepts/revisions-and-history/).

The viewer shows `history_unavailable`. The site keeps a whole [Workspace Bundle](/docs/reference/glossary/#term-workspace-bundle) only for its latest Revisions and every tag. Compare the two commits on a [Workspace checkout](/docs/reference/glossary/#term-checkout) with [diff](/docs/guides/review/diff/), or ask the MCP server. A past Bundle in a format this viewer can't read gives `history_unavailable` too. Rebuild the site with the current Archidocs.

The viewer lists several Revisions to pick from. The link's `at` or `vs` is a short sha that starts more than one Revision's sha. Pick one, or use more of the sha.

## With an agent

Ask "What changed in the Model since 21 July 2025?". [`get_changes`](/docs/reference/mcp/get_changes/) answers it, and [`list_history`](/docs/reference/mcp/list_history/) lists the Revisions.

Ask "Which decisions sit behind the Auth Service?". [`list_adrs`](/docs/reference/mcp/list_adrs/) answers it, and [`get_adr`](/docs/reference/mcp/get_adr/) returns one ADR.
