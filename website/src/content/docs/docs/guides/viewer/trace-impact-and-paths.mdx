Light up everything an outage reaches, or every path between two [Elements](/docs/reference/glossary/#term-element), with a [Lens](/docs/reference/glossary/#term-lens) on the diagram.

## Before you start

- You have a viewer open. See [Find an Element](/docs/guides/viewer/find-an-element/).

## 1. Turn on the Impact Lens

Select the Element that is down, then select **Upstream & downstream** in its Element panel. The Impact Lens marks every Element that depends on it, or that it depends on, with how many hops away it is.

Choose a direction on the Lens's chip. [Upstream](/docs/reference/glossary/#term-upstream-downstream) is everything that depends on the Element, so it is what an outage reaches. Downstream is what the Element depends on.

<Screenshot id="viewer-impact-lens" alt="The Service Landscape with the Impact Lens upstream of the Mainframe Banking System. Five boxes are marked Upstream 1, and the Personal Banking Customer is marked Upstream 3." />

## 2. Connect two Elements

Select the first Element, then select **Connect to…** in its Element panel. Select the second node on the diagram, or press `/` to find it. Escape cancels.

The Connect to… Lens lights the shortest paths between them, and picks every node on them. Choose **All ≤ 4 hops** on its chip to light every path of four hops or fewer.

<Screenshot id="viewer-connect-lens" alt="The Service Landscape with the Connect to… Lens from the Single-Page Application to the Mainframe: the Single-Page Application, the API Application and the Mainframe are lit." />

## 3. Close the Systems off the path

The Service Landscape opens every System, so the path lights the Services it goes through. Select the **−** on a System the path doesn't touch to close it and leave more room for the path.

## Check it worked

The location bar shows an **Impact** or **Connect** chip that names the Elements. The address holds the Lens: `impact=` and `way=` for impact, `from=` and `to=` for a path. On the demo, [everything upstream of the Mainframe ↗](https://big-bank.archidocs.dev/#/view/c2?impact=core:mainframe&way=upstream) is what a Mainframe outage reaches.

## With an agent

Ask "What breaks if the Mainframe is down?". [`get_impact`](/docs/reference/mcp/get_impact/) answers it, with how far upstream each Element is.

Ask "How does the Single-Page Application reach the Mainframe?". [`find_paths`](/docs/reference/mcp/find_paths/) answers it, with each Relationship on the way.
