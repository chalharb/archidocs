Archidocs is developed in the open, in the [chalharb/archidocs](https://github.com/chalharb/archidocs) repo on GitHub. Questions, bug reports and pull requests all go there.

## Ask a question

Check [Troubleshooting](/docs/help/troubleshooting/) and the [FAQ](/docs/help/faq/) first. If they don't answer it, [open an issue](https://github.com/chalharb/archidocs/issues/new) on GitHub.

## Report a bug

Open a [bug report](https://github.com/chalharb/archidocs/issues/new?template=bug_report.yml). The form asks for three things:

- The CLI version, which `archidocs version` prints.
- The command you ran.
- What it printed, copied in full.

## Ask for a feature

Open a [feature request](https://github.com/chalharb/archidocs/issues/new?template=feature_request.yml). Say what you're trying to do, then what you'd like Archidocs to do about it.

## Report a vulnerability

Don't open an issue. Report it privately, as [SECURITY.md](https://github.com/chalharb/archidocs/blob/main/SECURITY.md) describes.

## Contribute a change

[CONTRIBUTING.md](https://github.com/chalharb/archidocs/blob/main/CONTRIBUTING.md) says how to set up the repo, run the tests and the docs site, and open a pull request.

Everyone who takes part follows the [Code of Conduct](https://github.com/chalharb/archidocs/blob/main/CODE_OF_CONDUCT.md).
