A [Team](/docs/reference/glossary/#term-team) is a group that can own things. Teams are defined once, in `workspace.yaml`, so every Project uses the same ids:

```yaml file="examples/kitchen-sink/archidocs/workspace.yaml"
```

## Every Element has one Owner

The [Owner](/docs/reference/glossary/#term-owner) is the one Team accountable for an Element. It is never blank and never shared: when something breaks, there is one Team to ask.

The Owner defaults to the Team that owns the Project, from `project.yaml`:

```yaml file="examples/kitchen-sink/archidocs/sink/project.yaml"
```

Set `owner` on an Element only when it differs. In the Kitchen sink, the Core Team owns the Project, the Edge Team owns the web front end, and the Data Team owns the datastore and the broker:

```yaml file="examples/kitchen-sink/archidocs/sink/model.yaml" region="systems"
```

A child inherits nothing from its parent: Shop's Services are owned by Core, unless they say otherwise, whoever owns Shop.

## What else has an Owner

- A **Relationship** belongs to its consumer's Owner: the Team that depends on something is the one that declares it.
- A **Deployment** belongs to its Service's Owner.
- A **Deployment Target** has an Owner of its own, defaulting to its Project's Team, like an Element. Big Bank's Platform Team owns the AWS region, but the Core Banking Team owns the data centre declared beside it.

## Owners must exist

An `owner` that names no Team is an error, with a suggestion when it is close to one:

```yaml file="website/samples/misspelt-owner/archidocs/shop/model.yaml" fails="unknown-team"
```

`archidocs check` reports [`unknown-team`](/docs/reference/rules/unknown-team/) and suggests `payments`. Add a new Team to `workspace.yaml` first.

## Ownership in the viewer and MCP

Every node in the viewer and in an exported diagram carries its Owner: a coloured stripe with the Team's short code, so the colour never carries it alone. The **Team** Lens highlights what one Team owns, and the Teams tree lists each Team's Elements.

Over MCP, [`list_owned`](/docs/reference/mcp/read-tools/#list_owned) answers "what does my Team own?" and [`list_teams`](/docs/reference/mcp/read-tools/#list_teams) lists the Teams. A Saved View can select a Team's Elements with a `{team}` selector, or open with the Team Lens.
